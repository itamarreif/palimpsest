# Plan Checkpoint

1. Read the issue, current plan, and verified implementation state.
2. Classify discoveries as aligned, bounded deviation, or structural deviation.
3. Keep aligned plans unchanged except for completed work and verification.
4. Route bounded deviations to `plan-revision`.
5. Mark structural deviations `stale` and re-plan before continuing.
6. State the next unblocked work item and any blocker.
